#Progranmacion-1
Este repositorio contiene los programas y ejercicios desarrollados durante la materia programacion 1.
Los ejercicios están organizados por temas, y cada programa se encuentra en su propia carpeta.
##Programas incluidos
###Alumnos1
Pone calificaciones y nombres en listas separadas.
###Alumnos2
Lista los elementos como [nombre, calificación].
###Baraja
Imprime las cartas de la baraja.
###Barras_NumPy
Imprime barras y luego las ordena.
###Blackjack
Juego de blackjack contra el programa.
###CalculoAreas
Calcula distintas areas a elección.
###CalculoVolumenEsfera
Calcula el volumen de una esfera.
###ContraseñaSegura
Verifica una contraseña hasta que sea segura.
###DiasDelMes
Indica cuantos dias tiene un mes segun el año.
###EsVocal
Indica si una letra es vocal o no.
###FechaNacimiento
Convierte una fecha de nacimiento a una cadena de 6 caracteres.
###Feriado
Calcula la feria a proporcionar segun el pago recibido.
###FuncionAreaTriangulo
Una funcion para calcular el area de un triangulo.
###FuncionAreaTriangulo2
Una funcion para calcular el area de un triangulo.
###FuncionCadenaInversa
Una funcion para invertir una cadena.
###FuncionPrimos
Una funcion para saber si un numero es primo.
###Genio_y_Figura
Imprime figuras de asteriscos (reloj de arena, rombo, moño y copa) de tamaño impar entre 5 y 21, rellenas o huecas.
###Numero_Magico
Se juega al numero magico, el usuario tiene que adivinarlo con cierto numero de intentos, con cada fallo proporcionando una pista.
###Numeros_Primos
Indica si un numero es primo.
###NumerosRepetidos
Borra los numeros repetidos.
###NumerosRomanos
Convierte numeros a numeros romanos.
###NumMayor_o_Menor
Indica que numero es mayor y menor.
###Palindromos
Indica si una cadena es un palindromo.
###ParesImpares
Indica si un numero es par o impar.
###PrimeraVocal
Imprime la primera vocal.
###Promedio
Calcula el promedio de un estudiante.
###PromedioGrupal
Calcula el promedio grupal y quienes tienen una calificacion superior.
###Tabla_del_10
Muestra la tabla del 10 del numero introducido.
###Triangulos
Practicas para imprimir triamgulos de diversas formas.
